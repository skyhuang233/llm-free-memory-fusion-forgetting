2.2 Structured and Graph-Based Memory
Graph-based approaches have emerged as a powerful way to endow LLMs with associative recall. HippoRAG and HippoRAG 2~\cite{} build graphs over entities and passages and use personalized PageRank to retrieve multi-hop evidence. Zep~\cite{} and Mem0’s graph extension~\cite{} maintain temporal knowledge graphs as a memory layer for agents while ComoRAG~\cite{} organizes long narratives into cognitively-inspired memory structures for iterative RAG. SGMem~\cite{} represents dialogue as sentence-level graphs connecting sentences within and across sessions. Our work is closest in spirit to HippoRAG 2 and SGMem but differs in two key aspects: (i) we adopt an event-centric representation rooted in neo-Davidsonian semantics~\cite{} where enriched EDUs—rather than triples or raw sentences—are the primary memory units; and (ii) we couple graph-based retrieval with LLM-based recall-oriented filtering over both EDUs and argument nodes which is particularly important for the implicit unnamed references prevalent in less knowledge-intensive conversations.
