3.3 Virtual Agent Architecture
Every agent \{L}_{i} incorporates modules from generative agent architecture~\cite{bib.bib45}. The agent has two functions: (1) reflect & respond; and (2) image sharing & image reaction. The agent is asked to primarily use the reflect & respond function while employing image sharing & image reaction function judiciously and appropriately within the context of the conversation.
