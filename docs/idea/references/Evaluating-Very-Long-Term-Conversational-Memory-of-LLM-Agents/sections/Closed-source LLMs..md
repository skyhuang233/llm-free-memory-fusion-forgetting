Closed-source LLMs.
 We use state-of-the-art LLMs in our dialog generation pipeline to create a dialog dataset that is as realistic as possible. Unfortunately this meant employing the strongest commercial LLMs available through a paid API similar to many concurrent works that generate synthetic conversations ~\cite{bib.bib67 bib.bib38}. We will make the code for our generative pipeline publicly available in the hope that it can be made to work effectively with state-of-the-art open-source LLMs in the future.
