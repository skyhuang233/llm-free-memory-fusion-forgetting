3.3.2 Hierarchical Recall
Hierarchical recall operates in two stages: leaf selection at the base level followed by hierarchical recall propagation through memory subtrees.

#### Stage 1: Base-Level Memory Activation
Stage 1: Base-Level Memory Activation
 At L_{1} dual-channel scoring combines semantic similarity and lexical matching through fusion: s(mqK)=\lambda{s}_{\{sem}}(mq)+(1-\lambda){s}_{\{lex}}(mK) where {s}_{\text{sem}} is cosine similarity between embeddings {s}_{\text{lex}} is BM25 score for keyword matching and \lambda\in[01] balances both channels. The top-k_{1} scoring segments form the leaf set \Omega_{1}(qK).

#### Stage 2: Hierarchical Recall Propagation
Stage 2: Hierarchical Recall Propagation
 For each leaf m\in\Omega_{1} we collect its ancestors at the hierarchy levels selected by \{S}(c): \displaystyle\{A}(mc)=\{m^{\prime}\!\in\!M:m\!\preceq\!m^{\prime}\ \ell(m^{\prime})\!\in\!\{S}(c)\} where m\preceq m^{\prime} denotes that m^{\prime} is an ancestor of m and \{S}(c) restricts recall to levels specified by complexity c. The complete candidate set integrates leaves and their ancestors: \Omega_{c}(qK)=\Omega_{1}(qK)\cup\bigcup_{m\in\Omega_{1}(qK)}\{A}(mc)
 For brevity we denote this candidate set as \Omega_{c}. The number of recalled memories per level is determined by query complexity; specific configurations are detailed in Appendix B.3[ref_id]A2.SS3.
