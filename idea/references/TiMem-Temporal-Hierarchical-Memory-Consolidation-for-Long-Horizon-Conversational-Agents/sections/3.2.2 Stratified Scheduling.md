3.2.2 Stratified Scheduling
Memory consolidation follows a two-tier scheduling strategy that balances freshness and efficiency:
 •
 Online consolidation (L_{1}): Factual segment memories m^{(1)}_{k} are generated immediately as the dialog progresses. With w_{d}=1 dialog turn (one user–assistant exchange) the consolidator \Phi_{1} is invoked after each new turn to capture fine-grained evidence.
 •
 Scheduled consolidation (L_{2}-L_{5}): Higher-level memories m^{(i)}(g) are generated automatically when their temporal windows end. Upon closure of temporal group g\in\{G}_{i} the framework triggers \Phi_{i}(\{C}_{i}(g)\{H}_{i}(g);\{I}_{i}) to consolidate child memories into a higher-level more abstract representation.
 Thus this stratified design ensures that factual details are captured in real time while higher-level consolidation is aligned with predefined temporal boundaries.
