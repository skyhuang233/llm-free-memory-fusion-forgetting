Memory Primitives
At the core of EverMemOS is the MemCell, the atomic unit bridging low-level data and high-level semantics. Formally, a MemCell c is a tuple c = (E, F , P, M ), where: • E (Episode): A concise third-person narrative of the event, serving as the semantic anchor. • F = {f 1 , . . . , f n } (Atomic Facts): Discrete, verifiable statements derived from E for highprecision matching. • P (Foresight): Forward-looking inferences (prospections; e.g., plans and temporary states) annotated with validity intervals [t start , t end ] to support temporal awareness. • M (Metadata): Contextual grounding including timestamps and source pointers. This structure turns memory from a static record (E, F) into a temporally grounded representation that also supports Foresight (P ).
