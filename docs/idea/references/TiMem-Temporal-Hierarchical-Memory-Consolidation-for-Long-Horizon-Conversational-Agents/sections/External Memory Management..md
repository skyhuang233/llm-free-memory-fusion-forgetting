External Memory Management.
 Semantic clustering approaches including Mem0~\cite{bib.bib21} RAPTOR~\cite{bib.bib9} and MemTree~\cite{bib.bib41} organize memory through embedding-based similarity aggregation. Graph-based approaches including Zep~\cite{bib.bib13} LiCoMemory~\cite{bib.bib44} and Theanine~\cite{bib.bib45} explicitly model entity relations and temporal knowledge. Cognitively motivated frameworks such as A-MEM~\cite{bib.bib11} Nemori~\cite{bib.bib16} ENGRAM~\cite{bib.bib43} and RMM~\cite{bib.bib17} employ self-organizing or agentic mechanisms while preference-aware systems like MemoryBank~\cite{bib.bib14} and PAMU~\cite{bib.bib18} support personalization through dynamic updates. OS-inspired memory systems such as MemGPT~\cite{bib.bib6} MemoryOS~\cite{bib.bib7} and MemOS~\cite{bib.bib8} manage long contexts via hierarchical tiers and virtual memory mechanisms. However most existing approaches do not treat temporal structure as a first-class organizing principle resulting in fragmented memory representations and unstable long-horizon behavior.
