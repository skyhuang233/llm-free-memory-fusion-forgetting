# Project Structure

This repository is organized so the main workstreams are visible from the top level:

- `exp/` contains the experiment code, configs, evaluation pipeline, and result logs.
- `paper/` contains the manuscript source, bibliography, figures, and build outputs.
- `docs/` contains planning notes, workspace notes, and structure documentation.
- `figures/` contains shared visual assets used by docs and the paper.
- `references/` contains imported reference paper bundles and supporting material.
- `tools/` contains utility scripts used for workspace setup and other maintenance tasks.
- `llm-free-memory-fusion-forgetting-master/` is a legacy nested workspace snapshot kept only for reference.

Recommended day-to-day editing targets:

1. Use `exp/dfm_fusion/` for code changes and experiments.
2. Use `paper/` for manuscript updates.
3. Use `docs/` for planning or migration notes.
4. Use `figures/` and `references/` for supporting assets.
