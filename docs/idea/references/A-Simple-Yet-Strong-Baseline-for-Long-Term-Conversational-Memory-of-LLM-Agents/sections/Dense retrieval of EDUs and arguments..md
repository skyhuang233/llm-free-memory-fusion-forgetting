Dense retrieval of EDUs and arguments.
We encode the query with the same encoder: z_{q}=h(q). We first retrieve the top-K_{e} EDUs by cosine similarity between z_{q} and h_{\text{edu}}(e) obtaining a candidate set C^{\text{edu}}(q). In parallel we run an LLM-based mention detector on q to extract a set of surface mentions M(q)=\{m_{1}\dotsm_{M}\} corresponding to entities noun phrases and salient concepts. Each mention is embedded as h(m) and we retrieve top-K_{a} argument nodes for each mention using similarity between h(m) and h_{\text{arg}}(a) forming a candidate argument set C^{\text{arg}}(q).
