Phase III: Reconstructive Recollection
Building on theories of reconstructive memory ~\cite{b25}, retrieval in EverMemOS is modeled not as a static lookup but as an active Reconstruction process, guided by the principle of necessity and sufficiency. Given a query q, Ever-MemOS performs agentic retrieval grounded in MemScenes.
