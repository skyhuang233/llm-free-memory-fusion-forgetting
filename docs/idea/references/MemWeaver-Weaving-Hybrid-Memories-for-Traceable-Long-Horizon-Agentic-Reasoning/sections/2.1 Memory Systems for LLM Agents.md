2.1 Memory Systems for LLM Agents
LLM agents operating in long-horizon multi-step settings must retain information beyond fixed context windows motivating external memory mechanisms ~\cite{bib.bib19 bib.bib23 bib.bib8 bib.bib11 bib.bib20}. Existing approaches span retrieval-oriented memories that store interaction traces in external stores (e.g. vector databases) for cross-session access ~\cite{bib.bib39 bib.bib24} structured or controlled architectures that regulate long-term information via hierarchies or controllers (e.g. MemGPT SCM) ~\cite{bib.bib23 bib.bib30} and abstraction-based memories that distill reusable reasoning patterns or task-level insights ~\cite{bib.bib22 bib.bib37}. More recent agentic frameworks further enable continual memory evolution by adding revising or deleting entries across sessions ~\cite{bib.bib32 bib.bib2}. Despite this progress many systems still rely on coarse LLM-centric updates and provide limited support for temporally constrained reasoning and evidence-grounded correction at scale ~\cite{bib.bib39}.
