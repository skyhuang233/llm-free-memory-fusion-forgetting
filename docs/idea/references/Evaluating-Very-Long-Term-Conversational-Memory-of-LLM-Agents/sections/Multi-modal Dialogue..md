Multi-modal Dialogue.
 Multi-modal dialogue primarily consists of two types of tasks: image-grounded dialogue and image-sharing dialogue. The image-grounded dialogue task is centered around responding to questions~\cite{bib.bib3 bib.bib11 bib.bib24} or creating natural conversations related to specific images~\cite{bib.bib42 bib.bib50 bib.bib40 bib.bib66}. Conversely the image-sharing dialogue task focuses on selecting images that semantically align with the provided dialogue context~\cite{bib.bib59 bib.bib12 bib.bib29}. We use a method from the image-sharing dialogue task to create multimodal dialogs which are then evaluated as an image-grounded dialogue task.
