Context Management and Retrieval Efficiency. Beyond memory storage, efficient access to historical information remains a core challenge. Existing approaches primarily rely on either long-context models or retrieval-augmented generation (RAG). Although recent LLMs support extended context windows (OpenAI, 2025;~\cite{b18}Anthropic, 2025), and prompt compression methods aim to reduce costs (Jiang et al., 2023a;~\cite{b32}, empirical studies reveal the "Lost-in-the-Middle" effect ~\cite{b34,b28}, where reasoning performance degrades as context length increases, along-side prohibitive computational overhead for lifelong agents. RAG-based methods ~\cite{b30,b17}Jiang et al., 2023b), including structurally enhanced variants such as GRAPHRAG ~\cite{b20,b53} and LIGHTRAG ~\cite{b22}, decouple memory from inference but are largely optimized for static knowledge bases, limiting their effectiveness for dynamic, timesensitive episodic memory. In contrast, SimpleMem improves retrieval efficiency through Intent-Aware Retrieval Planning, jointly leveraging semantic, lexical, and symbolic signals to construct query-specific retrieval plans and dynamically adapt the retrieval budget, achieving token-efficient reasoning under constrained context budgets.
