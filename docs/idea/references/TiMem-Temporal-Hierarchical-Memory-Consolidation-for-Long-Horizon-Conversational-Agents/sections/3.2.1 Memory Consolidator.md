3.2.1 Memory Consolidator
At level i the consolidator generates new memories by prompting an LLM with (i) child memories (ii) historical memories and (iii) instruction prompts. \Phi_{i}:\{C}_{i}\times\{H}_{i}\times\{I}_{i}\to M_{i}
 In formula ( 1[ref_id]S3.E1) \{C}_{i} are child memories from level i{-}1 \{H}_{i} provides short same-level history for continuity and \{I}_{i} are instruction prompts. We use \{I}_{1}-\{I}_{2} for factual consolidation \{I}_{3}-\{I}_{4} for pattern consolidation and \{I}_{5} for profile representation. Example consolidator prompt is shown in Appendix E.3.1[ref_id]A5.SS3.SSS1.

#### Child Memories
Child Memories
 We group the conversation timeline into intervals g\in\{G}_{i} (e.g. sessions days). For i\geq 2 child memories for each group are the lower-level nodes whose time spans fall inside g: \{C}_{i}(g)=\{m\in M_{i-1}:\tau(m)\subseteq g\}\quad i\geq 2 At the base level (L_{1}) child memories are the raw dialog turns within the interval.

#### Historical Memories
Historical Memories
 \{H}_{i} consists of the w_{i} most recent memories from the same level M_{i}:
 \{H}_{i}=\{m^{(i)}_{-j}:1\leq j\leq w_{i}\}
 where m^{(i)}_{-j} denotes the j-th most recent memory at level i. This sliding window provides continuity across temporal groups. We set w_{i}=3 across all levels to ensure consolidation consistency.
