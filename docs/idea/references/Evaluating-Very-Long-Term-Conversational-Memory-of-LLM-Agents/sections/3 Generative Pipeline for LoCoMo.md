3 Generative Pipeline for LoCoMo
An overview of our generative pipeline for LoCoMo is shown in Figure 3. We create two virtual agents named \{L}_{1} and \{L}_{2} each initialized with a LLM \{M} (i.e. gpt-3.5-turbo). To start unique persona statements p are assigned to each agent \{L}_{i} ensuring the integration of distinct personalities into their dialogues (§ 3.1[ref_id]S3.SS1). To mirror real-life experiences we create a temporal event graph \{G} for each agent which illustrates a realistic sequence of life events (§ 3.2[ref_id]S3.SS2). The LLM agent architecture~\cite{bib.bib45} is utilized for each agent \{L}_{i} enabling them to effectively memorize and reflect conversation history into ongoing dialogues (§ 3.3[ref_id]S3.SS3). Further each agent \{L}_{i} can share coherent images thereby enhancing the multi-modal dialogue aspect. Finally human annotators are tasked with manually filtering and refining the generated data (§ 3.4[ref_id]S3.SS4).
