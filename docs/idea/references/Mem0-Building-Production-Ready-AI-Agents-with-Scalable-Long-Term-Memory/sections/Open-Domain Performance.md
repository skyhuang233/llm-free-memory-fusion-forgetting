Open-Domain Performance
In open-domain settings the baseline Zep achieves the highest F1(49.56) and J(76.60) scores edging out our methods by a narrow margin. In particular Zep’s Jscore of 76.60 surpasses \texttt{Mem0}^{\tiny g}’s 75.71 by just 0.89 percentage points and outperforms Mem0’s 72.93 by 3.67 points highlighting a consistent if slight advantage in integrating conversational memory with external knowledge. \texttt{Mem0}^{\tiny g}remains a strong runner-up with a Jof 75.71 reflecting high factual retrieval precision while Mem0follows with 72.93 demonstrating robust coherence. These results underscore that although structured relational memories (as in Mem0and \texttt{Mem0}^{\tiny g}) substantially improve open-domain retrieval Zep maintains a small but meaningful lead.
