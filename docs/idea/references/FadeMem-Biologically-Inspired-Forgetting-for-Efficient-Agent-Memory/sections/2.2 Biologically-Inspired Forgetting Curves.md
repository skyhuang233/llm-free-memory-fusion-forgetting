2.2 Biologically-Inspired Forgetting Curves
We measure time in days consistent with our 30-day evaluation setup. We model memory decay using differential exponential functions that simulate human forgetting patterns consistent with Ebbinghaus’s forgetting curve: v_{i}(t)=v_{i}(0)\cdot\exp\left(-\lambda_{i}\cdot(t-\tau_{i})^{\beta_{i}}\right) The decay rate adapts to memory importance: \lambda_{i}=\lambda_{\text{base}}\cdot\exp(-\mu\cdot I_{i}(t)) where \lambda_{\text{base}} approximates human short-term memory decay rates and \mu modulates the importance effect. The shape parameter \beta_{i} depends on the memory layer: \beta_{i}=\begin{cases}0.8&\text{if }m_{i}\in\text{LML}\qquad\text{(sub-linear decay)}\\ 1.2&\text{if }m_{i}\in\text{SML}\qquad\text{(super-linear decay)}\end{cases} These values mirror biological memory consolidation where long-term memories exhibit slower more gradual decay. Memory consolidation occurs during access simulating the strengthening effect observed in human memory: v_{i}(t^{+})=v_{i}(t)+\Delta v\cdot(1-v_{i}(t))\cdot\exp(-n_{i}/N) where \Delta v is the base reinforcement strength n_{i} counts accesses within a sliding window of W days and N implements diminishing returns consistent with spacing effects in human learning. Memories undergo automatic pruning when their strength falls below \epsilon_{\text{prune}} or they remain dormant beyond T_{\text{max}} days.
 Half-lifeWith time measured in days the half-life of memory m_{i} under our model is t_{1/2}(i)=\Big(\tfrac{\ln 2}{\lambda_{i}}\Big)^{\!1/\beta_{i}}\quad\lambda_{i}=\lambda_{\text{base}}\exp(-\mu I_{i}(t)). At I_{i}(t)=0 this gives t_{1/2}\approx 11.25 days for LML (\beta_{i}=0.8) and t_{1/2}\approx 5.02 days for SML (\beta_{i}=1.2) when \lambda_{\text{base}}=0.1.
