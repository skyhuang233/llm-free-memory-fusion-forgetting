3.3.3 Recall Gating
Recall gating implements recall-time forgetting: after collecting candidate memories we keep only the truly useful ones for answering the query.
 The recall gating module \phi receives query q its complexity c and the candidate set \Omega_{c} organized by hierarchy levels. It prompts an LLM to determine whether each memory should be retained: \Omega_{\phi}(qc)=\{m\in\Omega_{c}\mid\phi(mqc)=\text{retain}\} where \phi(mqc) denotes the LLM’s retention decision for memory m given query q and complexity c. Query complexity guides the breadth of retention: simple queries favor precision by retaining fewer memories while complex queries favor recall by accepting broader context. Example recall gating prompt template is in Appendix E.3.2[ref_id]A5.SS3.SSS2.
 The retained memories are ranked by hierarchy level and temporal proximity within each level: \displaystyle\Omega_{\{final}}(qc)=\{sort}\!\big(\Omega_{\phi}(qc)\ \{key}{=}(\ell(m)|t_{q}{-}t_{m}|)\big) where \ell(m) denotes the hierarchy level t_{q} is the query time and t_{m}=t_{\text{end}}(m) so |t_{q}-t_{m}| measures temporal distance organizing relevant memories by recency within each consolidation level thereby ensuring concise temporally coherent and information‑dense responses.
