Related Work
LLMs have been widely applied across diverse domains, including dialogue systems, decision-making agents, code generation, and scientific reasoning ~\cite{b43}Li et al., 2025a;~\cite{b14,b4,b38,b26}Jiang et al.). Their strong in-context learning and generative capabilities make them a natural foundation for building autonomous agent systems that require long-horizon interaction and memory management. Recent research on long-term memory for LLM agents can be grouped into three paradigms: (1) flat retrieval-based systems, (2) explicitly structured systems, and (3) policymanaged memory systems. Flat retrieval-based memory systems store salient facts, events, or summaries in flat/weakly structured repositories and rely on similarity search for recall. Mem0, LightMem, and MemoryBank emphasize efficient extraction, incremental updating, and personalization ~\cite{b5,b11}Zhong et al., 2024). Their main limitation is that flat memory offers limited abstraction and relational reasoning, which can hurt performance on tasks requiring multi-hop inference or cross-context integration. Explicitly structured memory systems organize memory into linked notes or graphs to support richer reasoning. A-MEM and O-Mem maintain evolving networks of notes via reflection and linking (Xu et al., 2025b;Wang et al., 2025); MemGAS further introduces multi-granularity memory with GMM-based organization and entropy routing (Xu et al., 2025a). MIRIX partitions memory into specialized types managed by multiple agents (Wang & Chen, 2025), while Zep builds a temporally aware knowledge graph for crosssession consistency ~\cite{b30}. While effective for structure-aware recall, these methods rely on fixed memory structures or routing strategies, limiting adaptability across conversational patterns and reasoning demands. Policy managed memory systems optimize memory behavior via learned policies or OS-inspired mechanisms. RLbased Memory-R1 and MIRA learn what to write/keep based on long-horizon rewards ~\cite{b42,b0}. MemoryOS adopts concepts such as hierarchical storage and eviction ~\cite{b19}, and Mnemosyne targets edge settings with redundancy pruning and probabilistic recall ~\cite{b18}. Despite improved adaptivity, most approaches still assume fixed structural biases or hand-crafted organization rules, motivating methods that treat memory structure as a decision variable.
