Evaluation of long-form NLG.
 LLMs are prone to generating verbose answers even when prompted to answer in short phrases. This creates challenges in evaluating the correctness of answers provided by LLMs and has been widely documented in NLP literature ~\cite{bib.bib6 bib.bib57 bib.bib25}. Our evaluation framework suffers from the same challenges when used for experimenting with LLMs.
