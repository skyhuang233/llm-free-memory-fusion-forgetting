3.1 Problem Setting
A conversation consists of sessions \{S}=\{s_{1}\dotss_{T}\} ordered by timestamps \tau(s). Each session s is a sequence of turns s=\big((\{spk}_{1}u_{1})\dots(\{spk}_{L_{s}}u_{L_{s}})\big) where u_{\ell} is the utterance from speaker \{spk}_{\ell}. At query time the agent receives a natural language question q and answer it conditioned on the entire conversation history. We assume access to an embedding encoder h(\cdot) that maps any text x to an embedding h(x)\in\{R}^{d} and a powerful QA model f_{\text{QA}} that takes (q\text{memory}) as input and generates an answer.
